<h1 align='center'>My CV Builder App</h1>

This App was a part of The Odin Project curriculum in Full Stack Javascript course. The main goal for this project was to build a React application where users can input their information and generate a CV/résumé.

As an outcome I have built customizable cv builder with real time visualization, where after finishing user can download pdf with their cv using html2pdf pluggin.

Main techonologies used:
<br>
• CSS
• React Js
